# Remembrance — Product / Demo Build Spec (for Replit)

**Target:** A polished, clickable **v1 demo** of the Remembrance consumer app. It must look and feel like the real product so it can be recorded for a demo video and shown widely. Scoring, voice analysis, and AI plans are **simulated/scripted** under the hood — but the experience must feel real and premium.

**Build on:** Replit. Web app, mobile-first, responsive.

**Brand:** Navy `#1E3A5F` · Cyan `#1BCEDF` · Cream `#F5F1EA`. Existing gradient wordmark. Large type, high contrast, senior-friendly, generous spacing. Warm and reassuring, never clinical.

**Positioning guardrail:** Wellness & monitoring. No "detect/diagnose/screen/dementia" language anywhere in-product. Include a small wellness disclaimer on assessments and plans.

---

## 0. Demo-mode principles (read first)

- **Everything is simulated.** No real telephony, no real biomarker analysis, no real LLM calls required. Results are scripted/randomized within realistic ranges.
- **Feel real.** Loading states, processing animations, and copy should read as if a real engine is working.
- **Demo controls:** include a hidden/dev **Demo Mode panel** to: reset state, jump to any screen, pre-load a user with history, and set processing-animation speed (Full / Fast / Skip). This is essential for filming and live demos.
- **Skippable processing:** the ~30s processing sequence must be skippable (skip tap) and speed-adjustable via Demo Mode.
- **Persist state** within a session so the dashboard, scores, goals, and history update as the user progresses through the demo.

## 2. Onboarding & intake (progressive)

**Goal:** Get just enough to generate the first plan; drip the rest later.

**Step 1 — Welcome:** brand, one warm line ("Let's understand how your brain is doing."), [Get started].

**Step 2 — Essentials (required):**
- First name
- Age
- Sex
- Education level (dropdown)
- "What brings you here?" (single select: *Family history* / *Noticing small changes* / *Staying proactive* / *Other*)

**Step 3 — Light health context (skippable, framed gently):**
- Any existing conditions? (optional multi-select + "prefer not to say")
- Family history of memory issues? (yes/no/unsure)

**Step 4 — Ready:** "We'll start with a quick baseline to set your Remembrance Score." → [Start baseline].

*(Remaining intake — meds, detailed lifestyle — is dripped as prompts over the simulated "first week"; for the demo, a single optional "complete your profile" card on the dashboard is enough.)*

## 3. Baseline assessment (all-domain)

A guided sequence that touches all five domains with **one short task each** (shortened versions of the weekly tests). Progress bar across the top ("Area 2 of 5"). Encouraging transitions between tasks ("Nice. Next up: memory.").

At the end → **Processing sequence** (full, all five sectors light up) → **Score reveal**.

---

## 4. Score reveal

- Big animated count-up to the composite **/100** Remembrance Score.
- The five-sector brain visualization fully "activated."
- One warm, non-alarming interpretation line based on score band (e.g. "You're off to a strong start." / "A great baseline to build from.").
- [See my dashboard].

**Never** show alarming language, risk categories, or disease framing.

---

## 5. Home dashboard

The daily home base. Contents:

- **Header:** greeting + wordmark.
- **Remembrance Score card (hero):** composite **/100** + the five-sector brain viz. This is the headline. **Do not show per-domain /20 here.** Small trend indicator ("+3 since last cycle").
- **Today's check-in card:** prompt to do the daily check-in (or "done for today ✓").
- **Today's goals card:** list of active goals with progress; tap to mark done.
- **Next test card:** "This week: Memory — 4 min" → [Start].
- **Explore areas:** five compact tiles (one per domain) → tap opens Domain Detail. Tiles show the domain name + a subtle status, not the raw /20.
- **(Optional) complete-your-profile nudge.**

---

## 6. Domain detail view

Opened by tapping a domain. **This is the only place the /20 appears.**

- Domain name + plain-language description ("Attention: staying focused and processing quickly.").
- **Domain score /20** with a simple gauge.
- **Written analysis** — 2–4 sentences on how they're doing in this area, plain and supportive (scripted per band for demo).
- **Trend** — small line/sparkline over past sessions.
- **Related guidance** — 1–2 tips from the care engine tied to this domain.
- [Back to dashboard].

---

## 7. Weekly domain test — general pattern

Each week focuses on **one domain**. Flow:

1. Intro card: which domain, why it matters (one line), est. time, [Begin].
2. The domain's interactive task **or** the voice prompt (modality varies by domain/week — see §8).
3. **Processing sequence** (§9) — only the active domain's sector lights up.
4. Result: that domain's /20 updates, composite recalculates live on return to dashboard, short takeaway shown.

Design every task to be **visually rich and highly interactive** — drawing, matching, tapping, building, recalling. Tactile and satisfying. **Read §8.0 first** — the experience principles below are what make this feel like the best assessment anyone has ever taken, and they apply to every single test.

## 8. The five domain tests (demo versions)

> All tasks are **original, non-branded adaptations** of public-domain cognitive paradigms (no MoCA/SLUMS branding or licensed items). Scoring is simulated.

### 8.0 Test experience principles — the invisible craft (apply to EVERY test)

Our user is often 45–70, sometimes anxious about exactly what we're measuring, sometimes not a confident touchscreen user. If a test ever feels like a *school exam* or a *doctor's evaluation*, we've lost. It must feel like a calm, well-designed activity that someone who cares built for them. These principles are non-negotiable and apply to all six tests below.

**1. No one ever fails from confusion.**
Every test opens with a **guided warm-up round that does not count**. It walks the user through the interaction with a live example ("Try tapping this one."). The real test only begins once they've succeeded at the warm-up. We measure cognition, never their ability to figure out our UI.

**2. Instructions are one sentence, plain, and optional-audio.**
One instruction on screen at a time, in large plain language ("Tap the blue circles. Ignore the rest."). A small speaker icon reads it aloud in the Remembrance voice for anyone who prefers listening. Never a paragraph of rules.

**3. Dignity over judgment — no red X's, ever.**
We never flash "Wrong" or a harsh buzzer. Incorrect actions get a soft, neutral response (a gentle dim, a quiet tone) and the test moves on. Correct actions get warm, satisfying reward. The emotional residue must be *encouraged*, never *graded*. The user should never be able to tell, in the moment, how "well" they're doing — that protects them from anxiety and protects the measurement from panic-spirals.

**4. Forgiving to the body.**
Large touch targets (min 44×44pt, ideally bigger). Generous hit areas around every element. Tolerant of tremor, drift, and imprecise taps. Drawing tasks smooth and forgive shaky input. Nothing requires fine-motor precision that a 68-year-old hand can't deliver.

**5. Calm pacing; pressure only when the construct demands it.**
Most tasks are unhurried. When a task genuinely measures speed (attention, processing), we frame timing gently — a soft progress ring, never a slamming countdown or a stressful beep. No task punishes a pause to breathe.

**6. Sensory reward makes it feel alive.**
Every meaningful action has layered feedback: a soft, pleasant **sound**, subtle **haptic** (where supported), and fluid **motion** (elements settle, glow, snap with spring physics). Cyan light responds to touch. It should feel as satisfying as a well-made game — the kind of tactile joy that makes someone *want* to come back next week.

**7. Always-oriented.**
The user always knows where they are ("Part 2 of 3") and that there's an end in sight. A quiet, unpressured progress indicator. No infinite or ambiguous tasks.

**8. Graceful control.**
A calm [Pause] is always available (pause → "Take your time. Ready when you are."). Mistaps are undoable where it makes sense. Nothing feels like a trap or a locked door.

**9. Adaptive, but invisibly.**
Difficulty nudges within safe bounds based on performance so the test stays in the sweet spot — never boring, never crushing — but the user never sees "difficulty increased." It just feels right.

**10. Beautiful restraint.**
Cream canvas, navy type, cyan as the single active accent. One thing to focus on at a time. No clutter, no ads, no competing color. The screen breathes. This calm *is* the premium feeling.

**Shared test shell (build once, reuse for all six):**
`Intro card → Warm-up (uncounted) → "Here we go" beat → Task rounds → gentle "All done, nicely done." → Processing sequence (§9) → result.` Consistent transitions, consistent encouragement, consistent pause control.

---

### 8.1 Complex Attention — "Focus Field"
*Measures: sustained attention, processing speed, impulse control.*

**What it should feel like:** a calm, satisfying game of catching the right lights — like tapping ripples on still water. Alert but never frantic.

- **Warm-up (uncounted):** one cyan circle drifts in slowly; the app says "Tap the blue circle." A gentle glow + soft chime on tap. "Perfect — that's all there is to it."
- **Core task:** shapes fade in one at a time on the cream field. Tap **only the cyan circles**; let everything else pass. Later rounds add a calm rule-flip announced clearly first ("Now tap the squares instead.") to measure flexibility.
- **Feel & motion:** each correct tap sends a soft ripple + pleasant tone + light haptic; the shape dissolves like it was "caught." Missed/incorrect taps just fade quietly — no penalty flash. A subtle timing ring exists for internal scoring but reads as ambient, not stressful.
- **Encouragement:** occasional warm interstitials ("You're locked in.") — never score feedback.
- **Accessibility:** shapes are large and well-spaced; color is never the *only* differentiator (circles vs squares carry the load, not hue alone).

### 8.2 Executive Function — "Connect the Path"
*Measures: planning, sequencing, mental flexibility.*

**What it should feel like:** tracing a glowing constellation — deliberate and rewarding, like drawing a line of light between stars.

- **Warm-up (uncounted):** three nodes (1 → A → 2). "Draw a line from 1 to A to 2." A luminous cyan trail follows the finger. "That's it — numbers and letters, taking turns."
- **Core task:** nodes labeled 1, A, 2, B, 3, C… are placed across the field. The user drags one continuous line connecting them in alternating order. The trail glows and "locks" each correct segment with a satisfying snap.
- **Feel & motion:** correct connections chime up a pleasant scale as the path builds. A wrong reach doesn't scold — the line simply won't lock and softly springs back to the last good node, with a quiet "not quite — try the next one." Momentum is preserved; the user never restarts from zero.
- **Timing:** measured, but shown only as gentle ambient progress.
- **Accessibility:** big nodes, thick forgiving line, high contrast; the finger doesn't have to be precise — snapping to the nearest valid node.

### 8.3 Learning & Memory — "Recall Chain"
*Measures: encoding + delayed recall (the heart of memory assessment).*

**What it should feel like:** being gently handed a few things to hold onto, then warmly welcomed to share what you kept — never a pop quiz.

- **Learn phase:** 5 everyday words appear one at a time as beautiful cards, each paired with a simple friendly illustration (dual-coding aids real encoding and lowers anxiety). The app says each word aloud as it appears. Unhurried. "Just take these in. No need to do anything yet."
- **Distractor phase:** a short, pleasant unrelated micro-activity (~20s of Focus Field) so recall isn't immediate — framed as "Let's do something else for a moment," not as a trick.
- **Recall phase:** "Which of these do you remember?" The user recalls by **tapping from a friendly word bank** (recognition-supported, far kinder than a blank text box for this audience) — or typing if they prefer. Remembered words fly up and settle into a warm "you remembered" row with a soft chime each.
- **Delayed recall:** near the end of the session the app gently returns: "Earlier we looked at five words — any come back to you now?" Same kind interface.
- **Dignity:** words not remembered are never highlighted as failures. The screen only ever celebrates what *was* recalled.

### 8.4 Language — "Name & Match"
*Measures: naming, comprehension, verbal fluency.*

**What it should feel like:** a relaxed, almost conversational back-and-forth — like chatting with something friendly, not being drilled.

- **Warm-up (uncounted):** a clear illustration of a common object (e.g. a chair). "What is this? Say it, or tap the word." Both input paths shown so no one is stuck.
- **Core tasks, mixed for variety:**
  - **Naming:** a warm, simple illustration appears; the user **says it aloud** (mic) or picks from options. Voice input feels magical here — position it as "just say it."
  - **Word–picture match:** a word appears; tap the matching image among four generously sized, clearly distinct pictures.
  - **Quick fluency:** "Name as many fruits as you can" with a calm 30–45s ambient timer; spoken answers pop onto the screen as friendly bubbles as they're detected (in demo, scripted/gently faked).
- **Feel & motion:** correct matches glide together and settle; fluency bubbles bounce in with a light pop. Warm and playful.
- **Accessibility:** always offer both speak and tap; illustrations are unambiguous and large; no obscure vocabulary.

### 8.5 Perceptual-Motor — "Draw & Copy"
*Measures: visuospatial processing, construction, coordination.*

**What it should feel like:** a calm, almost meditative drawing moment — beautiful ink flowing under the finger. This is the most human, tactile test; make it a small delight.

- **Warm-up (uncounted):** "Trace this line." A dotted guide; the user's stroke lays down smooth, weighted cyan ink. "Lovely. The canvas is yours."
- **Core tasks:**
  - **Clock draw:** "Draw a clock, then set the time to ten past eleven." A real, responsive canvas with smoothed strokes (input smoothing so shaky lines still look graceful). Optional faint guide toggle for accessibility.
  - **Figure copy:** a simple reference figure (cube, intersecting pentagons) sits calmly on the left; the user reproduces it on the right canvas. Side-by-side, unhurried.
- **Feel & motion:** the ink itself is the reward — pressure/velocity-weighted, smooth, premium (think a high-end drawing app). Gentle undo. When they finish and tap [Done], the drawing does a soft satisfying "set" animation.
- **Dignity:** no "accuracy" shown, no overlay comparing their drawing to a "correct" one. It's their drawing; we simply thank them for it.
- **Accessibility:** large canvas, thick default stroke, easy undo, no time pressure at all on this one.

### 8.6 Voice test (in-app voice prompt) — used on some weeks, not all
*Measures (production): vocal biomarkers, fluency, expression. Demo: scripted result.*

**What it should feel like:** talking to something warm and attentive that's genuinely listening — the most premium, "wow" moment in the whole product. Get this right and it's the clip that sells the demo.

- **Setup:** a calm full-screen moment. The Remembrance voice (TTS) speaks a warm prompt aloud *and* shows it in large text: e.g. "Tell me about a place you love, in as much detail as you'd like," or "Take a minute and tell me about your morning." Conversational, open, never a command.
- **Recording:** a single beautiful **mic orb** at center. Tap to speak; the orb becomes a **living waveform / breathing light** that responds fluidly to the user's voice in real time — the screen feels like it's listening. No harsh timer; a soft ambient ring shows there's plenty of time.
- **Reassurance:** small line — "No right answers here. Just talk." — to dissolve performance anxiety.
- **Finish:** tap the orb to stop → smooth handoff into the **Processing sequence** with a voice/biomarker flavor ("Listening to the rhythm of your speech…").
- **Demo reality:** capture (or simply permission) audio, do no real analysis, return a scripted result presented as vocal-biomarker analysis. The *feeling* of being heard is what we're building.
- **Assignment:** one or two weeks per cycle use the voice test (natural fits: Language, and a fluency/attention blend). Keeping it occasional makes it feel special.

## 9. Processing sequence (shared component) — the hero moment

Runs after **every** test. This is what makes the demo video pop.

- **Duration:** ~30 seconds at Full speed. **Skippable** (skip tap). Speed set by Demo Mode (Full / Fast / Skip).
- **Visuals, layered:**
  - Animated **waveform** (for voice) or **metric read-outs / data ticking** (for interactive tests).
  - The **active domain's sector** on the five-sector brain viz pulses and "lights up."
  - Progress phases with changing captions: "Processing responses…" → "Analyzing patterns…" → "Updating your Remembrance Score…".
- **Reveal:** smooth transition to the result — the domain /20 updates and, back on the dashboard, the composite /100 animates to its new value.
- Keep it premium and calm, not frantic. Cyan/navy motion on cream.

---

## 10. Care plan & goals

- **Plan view:** organized by the six categories — **Diet · Aerobic/Exercise · Health Checkups · Sleep · Social Engagement · Cognitive Training.** Each category shows 1–3 personalized recommendations (scripted per user for demo, presented as freshly generated).
- **Goal cards:** each has [Accept] / [Decline].
  - **Decline → swap once:** immediately offer one alternative goal.
  - **Decline the swap → log and move on** (card resolves quietly).
- Accepted goals flow to the **dashboard goals card** and the daily loop.
- Small wellness disclaimer at the bottom of the plan ("General wellness guidance, not medical advice.").

---

## 11. Daily check-in

- Quick, low-friction: mood (emoji/scale), sleep (hours or quality), "anything on your mind?" (optional text).
- On submit → dashboard check-in card marks done; feeds the progress view.
- One tap to complete the essentials; keep it under ~20 seconds.

---

## 12. Progress / cycle comparison report

Appears when a full 5-week cycle completes (or via Demo Mode to show it on video).

- **Headline:** "Since your last completed round of testing…"
- Composite /100 **then vs now** with the delta.
- A simple per-domain comparison (each /20 then vs now) — this is fine to show here, in the report context.
- One encouraging summary line tied to their trend.
- Ties changes to habits where possible ("Your sleep goals may be paying off.").

---

## 13. Demo Mode panel (dev only)

Hidden toggle (e.g. long-press logo or `?demo=1`). Controls:
- **Reset** all state.
- **Jump to screen** (any of the above).
- **Load sample user** (with baseline + partial history so the dashboard looks lived-in).
- **Processing speed:** Full / Fast / Skip.
- **Force score** (set composite + domain scores to stage a specific reveal for filming).

---

## 14. Build order (suggested)

1. Design system + brand tokens + brain-viz component.
2. Dashboard shell + Remembrance Score card (with dummy data).
3. Processing sequence component (reusable).
4. One interactive test end-to-end (suggest "Connect the Path") → processing → score update. Prove the loop.
5. Remaining four interactive tests + voice prompt.
6. Baseline flow (chains the shortened tests).
7. Onboarding/intake.
8. Domain detail view.
9. Care plan + goals (accept/decline/swap).
10. Daily check-in.
11. Cycle comparison report.
12. Demo Mode panel + polish pass.

---

## 15. Out of scope for this demo

Real telephony (Twilio/ElevenLabs) · real biomarker analysis (Canary Speech) · real scoring/normative data · real LLM plan generation + guardrails · payments · auth/security hardening · caregiver/clinician views · licensed clinical instruments · notifications. All parked for the production build.
