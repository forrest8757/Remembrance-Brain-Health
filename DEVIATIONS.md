# Deviations

Every place the Remembrance digital protocol or build differs from the NACC UDSv4 T-Cog paper protocol (Form C2T) or from the original build spec, with the rationale. Add an entry whenever a new deviation is introduced.

## Platform

| # | Deviation | From | Rationale |
|---|---|---|---|
| P-1 | React 19 instead of React 18 | Build spec (CLAUDE.md §2) | The workspace catalog pins React 19.1 for the existing apps. |
| P-2 | Packages live in `lib/*` and apps in `artifacts/*`, not `packages/*` and `apps/*` | Build spec (CLAUDE.md §3) | Matches the existing pnpm workspace layout. The package boundaries are unchanged. |
| P-3 | Response windows can also close on `silence` (VAD), in addition to `timeout`, `participant_done` and `discontinue` | Data model (CLAUDE.md §13) | Needed for specs whose window ends after a stated silence (e.g. the MoCA memory proposal of 10 s after the last word). Only used when a spec's `closeOn` includes it. |
| P-4 | Dev clips are voiced by macOS `say` (manifest `voice.devOnly: true`) until `ELEVENLABS_API_KEY` and `ELEVENLABS_VOICE_ID` are set | CLAUDE.md §5 | Lets the pipeline be built and tested before the ElevenLabs voice is chosen. Dev-voiced clips must never be used for a real administration. |
| P-5 | Web speech-to-text goes browser → our API relay (`/api/asr/stream`) → Deepgram. Without `DEEPGRAM_API_KEY` (or the API server) every web window reports `asrUnavailable` and goes to review | CLAUDE.md §6 | The vendor key never reaches the browser. The relay is unauthenticated: add session auth before any deployment, and sign Deepgram's BAA before real participants. |
| P-6 | Mic PCM for ASR is tapped with a ScriptProcessorNode | CLAUDE.md §6 | Deprecated but universally available. Replace with an AudioWorklet in `lib/audio`. |
| P-7 | "I need to stop for today" ends the administration with reason code 97 (other problem) | CLAUDE.md §7 | Placeholder until the P1 Session Shell defines the exit flow and whether 98 (verbal refusal) applies. |
| P-8 | Resuming after an interruption restarts the current step, including re-presenting stimuli, for specs with `onInterrupt: 'restart_step'` | CLAUDE.md §11 | Correct for the toy test only. Any real test whose spec forbids repetition must set `onInterrupt: 'invalidate'` (or a finer per-step policy). |
| P-9 | The standalone try-out runner (`/assess/:testId`) shows a 15 s "Scoring your answers…" screen, then the test's **official** scores (e.g. Number Span Q5a/Q5b/Q6a/Q6b, MoCA Q1d of 22) with a plain-language reason for each, and a comparison with people of the same age band and sex | CLAUDE.md §9 (SessionComplete shows no per-test scores) | Owner request (2026-09-30) so tests can be tried and checked one at a time. A multi-test session (P2 Orchestrator) must not show scores between tests, since they could cue later tests. |
| P-10 | Comparisons use Remembrance-internal norms: each participant's first completed administration per test, grouped by decade age band (18–39, 40s … 80+) and sex, shown only when the group has ≥30 other people. Birth year (not full date of birth) and sex are asked once in the profile | Build doc §3b | NACC norms don't transfer to this version (§3b), so no published norms are used. The endpoint is unauthenticated and trusts the client's participant id: dev only. Needs auth and a HIPAA review of the reference table (de-identified: hashed key, age, sex, education band, scores) before real participants. |
| L-1 | All built tests (T3, T6, T7, T8) | Instructions, examples, prompts and feedback are Remembrance-original wording, not the C2T script | C2T verbatim scripts | Owner decision 2026-10-01: no content marked as needing permission (build doc §3b; the NACC manual's instruments are "reproduced by permission"). Task, timing, prompt rules, branches and scoring are unchanged; spec versions bumped to 2.0.0. Results are even less comparable to NACC's published versions (already not normed per §3b). T1 MoCA-Blind is switched off (trademark/license) until the owner approves it. |

## Protocol

| # | Test | Deviation | From | Rationale |
|---|---|---|---|---|
| T1-1 | MoCA-Blind | Memory words at 1 per 1.5 s, vigilance letters at 1 per 2 s, on **both** web and phone | In-person MoCA (1 word/s) | C2T's phone-adapted rates (p. 15: 1.5–2 s; ≥2 s). One rate on both channels keeps a single standard; 1.5 s is the lower bound, closest to the in-person rate. |
| T3-1 | Number Span | Digits at 1 per second, onset to onset | Not stated in C2T | Digit-span convention and the MoCA rate in the same manual. User-approved default (2026-09-30). |
| T3-2 | Number Span | Response window closes 3 s after speech ends or 10 s with no speech, with a 30 s hard cap | C2T gives no window rule (build prompt ⟦propose⟧) | A self-administered test needs an explicit close. The cap guards against a stuck open window. |
| T3-3 | Number Span | Repeat requests get only "Just do your best." (once per window) | Build prompt ⟦confirm approved phrase⟧ | Items may not be re-presented. User-approved default. |
| T3-4 | Number Span | "Run of 3+" read as 3 same-direction steps (4 digits); evenly spaced whole items (3-6-9) also rejected | Build prompt generator constraints | The 3-digit reading fails 16 Form A items; the constraints must pass on Form A. |
| T3-5 | Number Span | Form A exempt from "no shared 2-digit chunks between paired trials" and "never reuse practice items" | Build prompt generator constraints | Form A itself breaks both (4 shared chunks; backward item 3-7-4 is the example). Enforced on generated forms. |
| T3-6 | Number Span | "I'm finished" button available in response windows | Paper protocol has no such control | Gives the participant control; the window still closes on its own. |
| T3-7 | Number Span | Instruction captions are shown on screen, including the practice examples (1–8–7, 2–9–8, 3–7–4, 7–3–6) | Audio-only paper protocol | CLAUDE.md §9 requires captions of instructions. With licensed Form A, the backward example 3–7–4 is also a test item, so it appears on screen. |
| T3-8 | Number Span | After an interruption, the block resumes at the current item and re-presents it | Not addressed in C2T | Resuming mid-item with no presentation is impossible; the re-presentation is logged (two windows for the item). |
| T3-9 | Number Span | Without a transcript (no ASR key or an outage), nothing is judged live: no practice feedback, no discontinue, no backward reminder | C2T examiner judges in real time | Every such administration goes to the review queue. With the Deepgram relay configured, live judging works on the web. |
| T1-2 | MoCA-Blind | Only Remembrance-original forms (B–D); the canonical words, digits, letters, sentences and pairs are never used | C2T Form A | Decision D5 (licensing and practice effects). Scores aren't comparable to published MoCA norms until equated. |
| T1-3 | MoCA-Blind | Vigilance taps on the screen (web) or the mouthpiece (phone); instructions still say "tap your hand" | C2T phone: tap the phone | Decision D11. The tap check teaches the on-screen button; the verbatim instruction is kept. |
| T1-4 | MoCA-Blind | Taps undetectable after one retry → vigilance not administered (reason 97), total 88 | C2T has an examiner to adapt | Decision D11: no voice-"yes" fallback, which would change the task. |
| T1-5 | MoCA-Blind | Orientation "place" credited for any natural answer naming where they are, checked against a one-time profile; mismatches go to review | C2T examiner knows the location | Decision D8. No street address is ever asked for or stored. |
| T1-6 | MoCA-Blind | Authored lines: category-cue frame ("Here's a hint: one of the words was …"), tap check ("Let's make sure your taps come through. Please tap once now." / "Please tap once more.") | Not scripted in C2T | Needed for self-administration. Approved by the user 2026-09-30. |
| T1-7 | MoCA-Blind | Delayed-recall cue and multiple-choice lines are spoken but never captioned | Captions of instructions (CLAUDE.md §9) | They carry the memory words or their categories (Firewall). |
| T1-8 | MoCA-Blind | Serial 7s stops after five answers detected in the streaming transcript; without live ASR it closes after 10 s of silence | Examiner says "stop" after 5 | Self-administration. |
| T1-9 | MoCA-Blind | Education adjustment (+1 if ≤12 years) from three answer bands (≤12 / 13–16 / 17+), stored separately | MoCA +1 point rule | Decision D10; only ≤12 vs more matters for the rule. |
| T1-10 | MoCA-Blind | After an interruption the current step restarts, which can re-present registration words | MoCA allows repeating instructions only | A per-step interrupt policy (invalidate registration, restart elsewhere) is not built yet. |

| T6-1 | Category Fluency | Practice feedback codes 1 and 3 use neutral frames ("No, that is / those are not articles of clothing…", "Some of those are correct, but not all of them are articles of clothing…") instead of echoing the participant's words | C2T practice table fills "___" with the participant's words | Echoing needs runtime TTS in the examiner voice (doc `⟦DECISION⟧`). Owner-approved 2026-10-01 as interim until voice agents/runtime TTS; reworded under L-1. Practice zone only. |
| T6-2 | Category Fluency | The 60-s window opens when the "…Ready? Begin." clip ends, about 0.5 s after the onset of "Begin." | Timer starts at the onset of "Begin." | Response windows open at line end. The cutoff itself is exact on window-relative word times. Fix: open the window at the "Begin." word onset. |
| T6-3 | Category Fluency | Forms B (Fruits) and C (Occupations) ship without the productivity check (lexicon entries at Zipf ≥ 3 within ±15% of Vegetables) | Build doc T6 form validator | No word-frequency source in the repo yet. Both are `equated: false`; norms compare Animals only. |
| T6-4 | Category Fluency | An interrupted trial restarts with a fresh 60 s; words from the interrupted attempt aren't scored | Spec silent | The interruption is flagged. Gives the participant extra exposure to the category. |
| T6-5 | Category Fluency | "Yes." is given only when the asked-about item is creditable, and a member named only inside a question isn't credited automatically (sent to review) | "If they ask… the examiner may say 'Yes.'" | Avoids saying "Yes" to "do unicorns count?". A reviewer decides on credit for the asked word. |
| T6-6 | Category Fluency | Out-of-lexicon words score 0 and go to human review; the rubric-constrained LLM classifier isn't built | Build doc: lexicon plus LLM fallback | Lexicons cover common answers (610 animals, 302 vegetables, 163 fruits, 367 occupations). |
| T6-7 | Category Fluency | A repeat request gets "Name as many … as you can in one minute.", once per trial, triggered by the on-screen repeat button | Repeat allowed "if the participant specifically asks" | Re-saying "Ready? Begin." mid-minute would be confusing; voice detection of repeat requests isn't built. |
| T6-8 | Category Fluency | Form A (Animals + Vegetables, the NACC pairing) is served by default (not behind LICENSED_CONTENT) | D5: canonical content behind the license flag | The build doc rates T6 license risk Low (public-domain paradigm). Owner approved rotating all three (2026-10-01); reversible by setting `licensed: true`. |
| T8-1 | Oral Trails | The examiner's real-time judgement is an automatic decoder: it waits 800 ms for a self-correction, never interrupts on low-confidence speech, and accepts sound-alike E-set letters (flagged) | C2T examiner stops errors immediately | Build doc §T8 architecture: a false interruption is worse than a missed error. Every correction's latency is logged against the 1.2-s budget. |
| T8-2 | Oral Trails | "Start with 1." (authored) when the very first element is wrong | No scripted line for this case | "You last said '[n]'" has no n yet. Owner approved 2026-10-01 ("start with one or A, whichever is right": the line names the sequence's first element). |
| T8-3 | Oral Trails | Letters in corrections and instructions are rendered phonetically for the voice ("ay", "bee", "see"); captions show the letters | — | TTS reads a lone "A" as "uh". Wording unchanged. |
| T8-4 | Oral Trails | One fixed form (no parallel forms) | CLAUDE.md §14.4 (≥3 forms) | Build doc's recommended default: counting is fixed; practice effects handled statistically. Alternates would change difficulty and need equating. |
| T8-5 | Oral Trails | An interrupted part restarts with a fresh timer | Spec silent | The interruption is flagged; a restarted speed task gives extra practice. |
| T8-6 | Oral Trails | A 15-s stall discontinues with code 996; failed Part B practice also 996; failed pre-test 997 (per the doc) | "Reason code 995–998" | Fixed default until the exit flow (P1) lets a person choose. |
| T8-7 | Oral Trails | The optional "Number-letter." reminder isn't used | "You may remind 'Number-letter'" | Optional; would need a rule for when. Set-loss errors get the standard correction. |
| T8-8 | Oral Trails | Speech for 2.5 s after a correction starts is ignored (barge-in by time, not by detecting the clip's end) | Doc: pause ASR while the examiner speaks | Correction clips are 1.0–2.7 s. A participant who restarts very quickly may need to repeat a number. |
| T7-1 | Phonemic Fluency | Scoring is automatic: a spelling resolver over the ASR text, Webster's 2nd (1934) as the dictionary, ~440 first names and a hand list of places as the gazetteer, rule-based inflection (plural/tense/comparative) | Examiner judgement | Build doc §T7 implementation. Benefit-of-the-doubt decisions and unknown words go to review. |
| T7-2 | Phonemic Fluency | The letter is shown on screen as a large glyph during each minute | Auditory-only administration | Build doc recommends it (task cue, not a memory stimulus; reduces F/S/TH mishearing and working-memory load). |
| T7-3 | Phonemic Fluency | Rule reminders are authored: "Remember, no names of people or places." / "Remember, no numbers." / "Remember, try not to give me the same word with different endings." | Doc: "remind the participant of that rule", no wording | Owner-approved 2026-10-01. The wrong-letter reminder is "Remember, the letter is F." (L-1). |
| T7-4 | Phonemic Fluency | Letter pairs B (S, W) and C (A, H) rotate in without the ±10% productivity check; comparisons pool all pairs | Build doc T7 alternate forms | No word-frequency source. `equated: false`. |
| T7-5 | Phonemic Fluency | The clarifying example is part of the go line ("Your first letter is F, as in fox. Ready? Go.") | Doc: an allowed additional example, always given | Under L-1 the wording is ours; the example is always given, and "Ready? Go." stays last, right before the timer. |
| T7-6 | Phonemic Fluency | Connectives that start with the letter ("and"/"also" under A, "well"/"what" under W, "so"/"see" under S) aren't scored | Every dictionary word with the letter counts | In running speech they're nearly always fillers. Affects forms B and C only. |
| P-11 | Battery session | Results are shown on the session completion page, after the last activity, with each test's explanation (behind "How it was scored") | CLAUDE.md §9: no per-test scores immediately | Never between tests (that could cue later tests); the session's end is the results flow for now. |
| P-12 | Battery session | Refreshing mid-test restarts that test; delay clocks keep running | P2: "Resume works across device refresh" | Session-level resume is complete; within-test resume follows each spec's interrupt policy (restart). Flagged `restarted_after_interruption`. |
| P-13 | Battery session | Session lexical collisions are logged, not blocked | CLAUDE.md §8: block for original forms | Current forms don't collide; re-picking on collision is the next step. |
