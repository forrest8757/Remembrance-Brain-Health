---
name: Brain explorer interaction direction
description: User-confirmed layout and transition preference for Remembrance’s wellness explorer.
---

Keep the five separate wellness-domain controls around the centered brain in a loose pentagon arrangement. When someone chooses a domain, the surrounding controls should recede, the brain should enlarge and move upward, and the selected domain’s information should appear within the same explorer box rather than scrolling the visitor down to it.

**Why:** The user explicitly said they loved the existing pentagon concept but wanted the domain transition to feel like a small page coming toward them, not a jump down the page.

**How to apply:** Preserve this spatial overview-to-detail interaction when iterating on or integrating the Remembrance explorer. The initial approval was for a visual mockup, not an instruction to change production automatically.
